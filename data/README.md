# Data directory

Place research data here during local experiments.

Recommended files:

```text
features.csv       # mission-level physical / damage features
series.npy         # multivariate time-series array, shape = (n_missions, sequence_length, n_variables)
mission_ids.csv    # optional mapping between row index and mission id
```

Do not upload confidential, sensitive, or unauthorized flight-test data to GitHub.
